Microsoft Defender for Endpoint Linux更新： 修复安全问题并增强企业终端防护能力
发布日期：2026-07-28
Microsoft Defender for Endpoint Linux EDR Security Update

微软发布 Microsoft Defender for Endpoint Linux 平台更新，用于提升 Linux 主机检测能力、 修复已发现问题，并增强企业环境中的终端安全管理能力。 此次更新针对 Linux Agent 运行稳定性、 检测能力以及安全策略执行进行了优化。

更新概述

产品： Microsoft Defender for Endpoint Linux Agent

发布日期： 2026-07-28

更新类型： 安全更新 / 功能增强

影响平台： Linux服务器、云主机、企业工作站

受影响版本

组件 旧版本 修复版本
mdatp Linux Agent 4.x早期版本 最新稳定版本
Microsoft Defender for Endpoint Linux 未更新环境 升级至2026年7月版本

修复的问题

本次更新主要解决以下问题：

  • 修复部分 Linux 主机 Agent 长时间运行后资源占用异常问题。
  • 改善恶意文件扫描过程中性能下降问题。
  • 增强威胁检测组件稳定性。
  • 修复部分安全策略无法正常同步的问题。
  • 优化与 Microsoft Defender XDR 集成通信。

技术分析

Microsoft Defender for Endpoint Linux 通过 Agent 部署在 Linux 主机中， 负责采集：

  • 文件行为
  • 进程活动
  • 网络连接
  • 系统安全事件
  • 恶意软件行为

安全响应

升级步骤

推荐升级流程： 


1.确认当前版本

mdatp health


2.查看Agent版本

mdatp version


3.停止旧版本服务


4.安装最新Defender Agent


5.重新启动服务


6.验证运行状态


mdatp health

升级验证方法

管理员可以通过以下命令确认更新是否成功： 



mdatp health

mdatp version

检查：

  • Agent状态是否为healthy。
  • 实时保护是否开启。
  • 安全智能版本是否正常更新。
  • 设备是否重新连接Defender门户。

部署注意事项

  • 生产环境升级前建议进行测试。
  • 确认Linux发行版本是否支持。
  • 避免Agent升级影响业务性能。
  • 确保服务器能够访问微软更新服务。

企业安全建议

  • 所有Linux服务器纳入EDR管理。
  • 保持Defender Agent自动更新。
  • 开启云端威胁分析功能。
  • 结合SIEM平台集中分析日志。
  • 定期检查未受保护Linux资产。

核心启示

  • Linux服务器已经成为攻击者重点目标。
  • 企业安全体系需要覆盖多操作系统环境。
  • EDR持续更新对于发现未知攻击非常重要。
  • 安全工具本身也需要及时维护升级。
