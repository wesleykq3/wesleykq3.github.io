FastJson RCE零日漏洞攻击美国企业：无需登录即可远程执行代码
发布日期：2026-07-27
CVE-2026-16723 Remote Code Execution Critical

安全研究人员发现，攻击者正在利用 Alibaba FastJson 开源 Java 库中的严重远程代码执行漏洞攻击企业系统。 攻击者无需账号认证，只需要发送恶意 JSON 数据， 即可在服务器环境中执行任意代码。

漏洞概述

漏洞编号： CVE-2026-16723

漏洞类型： 远程代码执行(RCE)

影响组件： Alibaba FastJson 1.x

攻击条件： 无需身份认证

该漏洞影响多个 FastJson 1.x 版本， 目前已经观察到攻击者针对企业服务器进行实际攻击。

漏洞原理分析

FastJson 在 JSON 反序列化过程中， 会根据输入数据中的类型信息解析对象。 攻击者可以利用 @type 字段控制对象加载过程， 最终触发远程代码执行。

攻击现状

目前攻击活动表现：
  • 攻击者正在扫描公网Java应用服务器。
  • 部分美国企业已经成为攻击目标。
  • 公开漏洞细节后攻击门槛进一步降低。

漏洞危害

  • 无需用户交互即可攻击。
  • 无需登录权限。
  • 可执行服务器权限范围内任意操作。
  • 可能导致数据泄露、后门植入。
  • 可能成为进一步攻击企业内网入口。

企业安全建议

建议立即执行：
  • 检查项目依赖中的 FastJson 版本。
  • 升级至安全版本或迁移其他JSON解析组件。
  • 开启安全模式限制危险类型解析。
  • 限制Java应用运行权限。
  • 监控异常JSON请求。

核心启示

  • 第三方开源组件已经成为攻击者的重要入口。
  • 反序列化漏洞长期属于高风险漏洞类别。
  • 企业需要建立软件供应链安全管理机制。
  • 漏洞公开后，应快速完成资产排查和修复。
